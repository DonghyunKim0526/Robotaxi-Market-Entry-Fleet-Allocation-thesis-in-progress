# Literature Review

This repository contains my literature review notes on data-driven optimization, distributionally robust optimization, contextual stochastic optimization, and optimization under multi-sourced data.

The main purpose of this repository is to organize the papers I reviewed, summarize their high-level ideas, and develop possible research questions for future discussion.

## Structure

- `first-meeting-literature-review/`: Literature review based on the references shared after my first meeting with Professor Siqian Shen.

## Main Topics

- Optimization under uncertainty
- Distributionally robust optimization
- Contextual stochastic optimization
- Multi-sourced data and information fusion
- Data-driven decision-making for logistics and resource allocation
