# 기본 모형 수치실험

기본 모형의 구현과 비용·제약·불확실성의 작동 원리를 **작은 사례 검증→연간 규모 검증→민감도·불확실성 점검** 순서로 살펴봅니다. 최종 배치는 재현용 기준입니다.

## 왜 두 사례를 사용하는가?

| 설계 질문 | 작은 사례 | 연간 큰 사례 |
|---|---|---|
| 주목적 | 직접 계산 가능한 구현·진입 경제성 점검 | 연간 규모의 수요 민감도·동률·표본 안정성 |
| 입력 근거 | 검증용 임의 정수 | 문헌 규모 참고+명시적 합성 가정 |
| 도시·시나리오 | 3·고정 공동 시나리오 10 | 3·난수 시드 2026의 공동 시나리오 10 |
| 수요 설계 | 시장 80·100·120, 동일한 선택확률 주변분포 | 시장 0.75·1·1.25배, 용량 경계를 오가는 선택확률 |
| 용량 | 전체 4, 도시 2, 생산성 10 | 전체 1,000, 도시 500, 생산성 8,760 |
| 독립 기준 | 60개 가능 결정 전수계산 | 도시별 비용을 결합하는 정확 DP |
| 추가 점검 | 경계·전환점·평균 고정 변동성·평균수요 동률 | 공통/도시별 민감도·전체 동률·반복 표본 |

[파라미터 근거](../../../../3.%20References/%E2%80%BB%20translation/B.%20parameter_rationale_baseline%28%ED%95%9C%EA%B8%80%29.pdf)는 관측·발표 추정·환산·가정을 구분합니다. 실제 코드의 선택확률은 보고서의 실행값을 기준으로 보며 실제 도시 수요 보정이 아닙니다.

## 공통 모형과 평가 규칙

진입·차량은 시나리오 공통이며 도시 간 용량 공유는 없습니다. 초기 진입비와 1년 차량비·기대 페널티를 합합니다.

```math
D_c^s=M_cp_c^s,\quad
T_c^s=\min(D_c^s,\kappa_cq_c),\quad
O_c^s=(\kappa_cq_c-D_c^s)_+,\quad
U_c^s=(D_c^s-\kappa_cq_c)_+.
```

```math
Z(y,q)=\sum_c(F_cy_c+K_cq_c)+\frac1{|S|}\sum_{s,c}(c_c^+O_c^s+c_c^-U_c^s),
\qquad \Delta Z=Z_{\mathrm{no\ entry}}-Z(y,q).
```

선택확률과 시나리오 발생확률은 다릅니다. 미진입 수요도 부족에 포함합니다. 처리율은 기대 처리/기대 수요, 활용률은 처리/배치 용량입니다. 미진입 대비 개선은 변경한 입력의 기준 비용으로 다시 계산합니다.

## 실험에서 점검한 내용

| 질문 | 방법 | 핵심 확인 |
|---|---|---|
| 식과 코드 일치 | 독립 풀이·목적값·균형·정수·한도 검사 | 보고된 사례에서 기준 풀이와 일치 |
| 경계 동작 | 사례별 규모에 맞는 8개 검사 | 수요·차량 0, 큰 진입비, 정확 균형 등 해석 가능 |
| 추가 진입 조건 | 처리 공헌과 고정비 비교 | 작은 사례의 추가 이익 8은 진입비 20보다 작음 |
| 배치 안정성 의미 | 성과와 모든 동률 해 확인 | 같은 배치라도 비용 변화, 다른 배치라도 동일 목적값 가능 |
| 불확실성 영향 | 평균 고정 변동성·공통 시나리오 평가 | 결정론적 목적값만으로 확률 성과 비교 불가 |
| 표본 안정성 | 연간 50·100·500개×5시드 | 학습 표본 변화와 실제 공통분포 성과를 구분 |

## 민감도와 불확실성: 대표 점검

![진입비에 따른 배치·서비스·비용 분해·미진입 대비 개선](smallcase/figures/06_F_zoom.png)

![시나리오 표본수에 따른 평균수요·공통 분포 추가비용](../../../B.%20baseline_model/2%29%20numerical_experiments/large_case/figures/annual/17_sampling.png)

**작은 사례:** 공통 진입비 8에서 두·세 도시 대안이 동률입니다. 추가 서비스 공헌과 고정비로 전환을 설명할 수 있어 목적함수 논리를 점검합니다. 다른 민감도는 대표 배치가 그대로여도 성과·동률 해를 바꿉니다.

**연간 사례:** 50개 표본은 공통 분포에서 추가비용 최대 약 1.73M, 500개는 다섯 시드 모두 0입니다. 실제 수요 분포의 정확도를 검증한 것이 아닙니다. 동률 72개는 동일한 한계가치에서 발생하며 도시별 비용이 이를 해소할 수 있습니다.

[작은 사례](smallcase/README.md)와 [영문 큰 사례](../../../B.%20baseline_model/2%29%20numerical_experiments/large_case/README.md)에 전체 설계·근거·해석이 있습니다. 음영은 동률 범위이며 별도 유도하지 않은 전환점은 시험 간격의 구간입니다.

## 재현 기준 결과

작은 사례는 유일한 (0,2,2), 비용 858입니다. 연간 사례는 대표 (132,368,500), 비용 약 166.264M과 동률 72개입니다. 서로 규모가 다른 두 비용을 직접 비교하거나 실제 도시 배치 권고로 해석하지 않습니다.
