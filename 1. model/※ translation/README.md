## 현재 모형: 도시 특성을 반영한 2단계 ER-DRO



### 수요 학습과 잔차 시나리오

시장규모 $M_c$는 고정하고 선택확률 $p_c$의 불확실성을 도시 특성 $x_c$와 오차로 설명합니다. 현재 특성은 무차량 가구 비율입니다. 관측 선택확률의 로짓 값을 회귀한 뒤 잔차를 후보 도시에 붙여 시나리오를 생성합니다.

```math
\ln\!\left(\frac{p^k}{1-p^k}\right)=\beta_0+\beta_1x^k+\varepsilon^k,
\qquad \hat\varepsilon^k=\ln\!\left(\frac{p^k}{1-p^k}\right)-\hat\beta_0-\hat\beta_1x^k.
```

```math
p_c^s=\sigma(\hat\beta_0+\hat\beta_1x_c+\hat\varepsilon^s),\qquad
D_c^s=M_cp_c^s,\qquad \sigma(z)=\frac{1}{1+e^{-z}}.
```

잔차 하나가 공동 시나리오 하나이므로 관측 수와 시나리오 수가 같습니다. 시그모이드는 선택확률을 0~1 사이로 유지합니다. 수요는 최적화 전에 계산되며 현재는 진입·차량 결정에 반응하지 않습니다.

### 1단계: 수요 관측 전 진입·차량 배치

진입 $y_c$와 정수 차량 $q_c$는 모든 시나리오에 공통으로 적용합니다. $F_c$는 진입비, $\bar q_c$는 도시 상한, $Q$는 전체 차량 한도입니다.

```math
\begin{aligned}
\min_{y,q}\quad &\sum_{c\in C}F_cy_c+\mathcal R_\zeta(q)\\
\text{s.t.}\quad &0\le q_c\le\bar q_cy_c &&\forall c\in C,\\
&\sum_{c\in C}q_c\le Q,\\
&y_c\in\{0,1\},\quad q_c\in\mathbb Z_{\ge0} &&\forall c\in C.
\end{aligned}
```

```math
\mathcal R_\zeta(q)=\min_{\tau\in\mathbb R}
\left\{\tau+\frac{1}{|S|(1-\zeta)}\sum_{s\in S}
\big(H(q,D^s)-\tau\big)^+\right\},\qquad 0\le\zeta<1.
```

목적함수는 진입비와 2단계 비용의 CVaR를 합합니다. $\zeta=0$이면 경험적 평균인 ER-SAA로 돌아가고, 값이 커지면 큰 비용 시나리오를 중시합니다. 시나리오마다 별도 차량 배치를 선택하는 것은 아닙니다.

### 2단계: 시나리오별 유휴 용량·미충족 수요

1단계 배치가 고정되고 시나리오 수요가 주어졌을 때 유휴와 부족 비용을 계산합니다. $\kappa_c$는 차량당 처리 용량이며 $c_c^+,c_c^-$는 통행당 유휴·부족 비용입니다.

```math
\begin{aligned}
H(q,D^s)=\min_{O^s,U^s}\quad
&\sum_{c\in C}(c_c^+O_c^s+c_c^-U_c^s)\\
\text{s.t.}\quad
&\kappa_cq_c-D_c^s=O_c^s-U_c^s &&\forall c\in C,\\
&O_c^s,U_c^s\ge0 &&\forall c\in C.
\end{aligned}
```

```math
O_c^s=\big(\kappa_cq_c-D_c^s\big)^+,\qquad
U_c^s=\big(D_c^s-\kappa_cq_c\big)^+.
```

위첨자 +는 0과 해당 식 중 큰 값입니다. 2단계는 도시·시나리오별로 분리되고, 수요 관측 후 도시 사이에서 차량을 이동하지 않습니다.

### 확장형: 두 단계를 하나의 문제로 풀이

실행 MILP는 1단계 제약과 모든 시나리오의 2단계 제약을 함께 넣습니다. CVaR의 양의 부분은 원문의 보조변수로 선형화합니다.

```math
\min_{y,q,O,U,\tau,w}\quad
\sum_{c\in C}F_cy_c+\tau+
\frac{1}{|S|(1-\zeta)}\sum_{s\in S}w^s,
```

```math
w^s\ge\sum_{c\in C}(c_c^+O_c^s+c_c^-U_c^s)-\tau,\qquad
w^s\ge0,\quad\tau\in\mathbb R.
```

$y,q$는 공통 1단계 결정, $O^s,U^s$는 시나리오별 2단계 변수, 문턱값과 초과비용 변수는 CVaR 표현입니다. 단계는 결정 시점과 역할의 구분이지 두 문제를 독립적으로 한 번씩 푼다는 뜻이 아닙니다. 진입비 대신 예산·도시 수 제약을 두는 변형도 있습니다.

개정 모형은 별도 차량비 항을 생략합니다. 문서의 계수 흡수는 기대값에서는 항등식이지만 일반 CVaR에서는 근사이므로 모든 위험계수에서 이전 기본 모형과 동일하다고 해석하지 않습니다.

## 수치실험: 무엇을 점검하는가?

참 수요 생성모형을 아는 합성 환경에서 **학습→시나리오→최적화→독립 평가** 절차, 도시 특성 정보의 가치, 평균/꼬리비용의 교환관계, 자료 수와 가정 변화에 대한 민감도를 점검합니다.

### 세팅과 비교 설계

| 항목 | 설정과 목적 |
|---|---|
| 후보 특성 | 18개 도시의 중심 카운티 대리값; ACS 2019–2023 무차량 가구 비율 약 0.054–0.777 |
| 시장규모 | 실제 가구 수×10; 배수 10은 합성 가정 |
| 참 선택모형 | 절편 −3.5, 기울기 0.8, 로짓 정규오차 표준편차 0.3 |
| 학습자료 | 15개·200개 합성 관측으로 계수와 잔차 추정; 최적화에는 참 계수를 제공하지 않음 |
| 자원 | 생산성 8,760, 도시 상한 150; 기대 수요 약 60%에 해당하는 차량(보고 사례 267대) |
| 비용 | 유휴 1, 부족 1·5·10; 진입비는 100,000×부족 계수로 비율 유지 |
| 위험계수 | 0·0.5·0.9; 0은 ER-SAA |
| 비교 대상 | 도시 특성 ER-SAA, 도시 특성 ER-DRO, 도시 특성 미사용 모형 |
| 독립 평가 | 참모형에서 별도 생성한 1,000개 공통 시나리오 |
| 지표 | 표본 외 평균·상위 10% 꼬리비용, 별도 1,000개 자료의 회귀 진단 |

학습·잔차 생성·최적화 후 결정을 고정해 평가합니다. 학습 내 목적값만으로 일반화 성능을 판단하지 않습니다. 평가 꼬리수준은 최적화 위험계수를 바꿔도 0.9로 고정합니다.

### 1. 수요 학습이 의도한 신호를 회복하는가?

![로짓 회귀·잔차·예측 진단](../C.%20ER-DRO_model/figures/fig1_f_diagnostics.png)

200개 관측에서 추정 기울기 0.665, 잔차 표준편차 0.298은 참값 0.8·0.3과 가깝습니다. 평가 결정계수는 약 0.143이며 특성 미사용은 −0.013입니다. 약한 신호로 설계했기 때문에 낮은 설명력 자체가 정보의 의사결정 가치가 없음을 뜻하지 않습니다.

잔차 그림은 이 합성 환경에서 재사용 가정을 진단합니다. 실제 도시 간 전이·독립성을 증명한 것은 아닙니다.

### 2. 도시 특성과 DRO는 각각 무엇을 바꾸는가?

![위험계수에 따른 독립 표본 평균·상위 10% 꼬리비용](../C.%20ER-DRO_model/figures/toy_oos_vs_zeta.png)

| 도시 특성 사용, 관측 200개·부족계수 5 | 위험계수 0 | 0.5 | 0.9 |
|---|---:|---:|---:|
| 표본 외 평균비용(백만 정규화 단위) | 12.46 | 12.67 | 14.22 |
| 상위 10% 꼬리비용 | 22.79 | 22.29 | 21.62 |

**DRO 효과:** 0→0.9에서 평균비용 약 14% 증가와 꼬리비용 약 5.1% 감소를 교환합니다. 평균비용을 무조건 낮추려는 비교가 아닙니다.

**도시 특성 효과:** 같은 위험수준의 특성 미사용 대비 평균비용 개선은 0에서 약 1–3%, 0.5에서 3–15%, 0.9에서 4–19%입니다. 위험계수를 키우는 효과와 정보의 가치는 별도 비교입니다.

**소표본 한계:** 관측 15개·특성 미사용에서는 꼬리비용이 22.79M→23.20M으로 악화되기도 합니다. 특성 사용 모형의 15개·200개 간 평균비용 차이 약 0.8–3.1%도 해당 합성 실행의 결과이지 보편적 소표본 보장이 아닙니다.

### 풀이 방식 점검

확장형과 L자형 분해법을 1% 종료 허용오차로 비교했습니다. 분해법의 실행 가능한 비용은 확장형보다 약 0.43–0.65% 높고 해당 작은 사례에서는 시간이 더 걸려 이후 실험은 확장형을 사용합니다. 정확히 같은 최적해를 얻었다거나 분해가 항상 빠르다는 결론은 아닙니다.

## 실제자료 적용을 위해 남은 일

운영도시의 센서스 구역 자료로 학습하고 후보도시의 구역별 수요를 합산하는 계획입니다.

```math
p_{cj}^s=\sigma(\hat\beta_0+\hat\beta_1x_{cj}+\hat\varepsilon^s),\qquad
D_c^s=\sum_{j\in J_c}M_{cj}p_{cj}^s.
```

ACS/NHTS로 시장규모·특성을 구성하고 통행기록으로 선택비율을 관측합니다. SF→LA 검증으로 예측오차·잔차 전이를 확인한 뒤 새 도시에 적용합니다. 분자·분모의 지역·기간, 공급 부족에 의한 관측 왜곡, 잔차 재사용, 학습 범위 중첩은 아직 점검 과제입니다. 완료된 합성 실험과 별도의 계획입니다.
