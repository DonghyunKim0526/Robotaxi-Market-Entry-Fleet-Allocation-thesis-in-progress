# 초기 모형 정식화

## 비교한 정식화

| 모형 | 목적함수 관점 | 추가한 내용 |
|---|---|---|
| 기본 재고결정 | 기대 유휴+가중 미충족 | 금전 보정 전 배치 기준선 |
| 비용형 | 진입·차량비+시나리오 페널티 | 추가 도시의 고정비 |
| 이익형 | 처리 통행 공헌이익−진입·차량비 | 처리량과 수익 연결 |
| 복수 페널티 | 유휴·부족 이후 결과 구분 | 미처리 손실의 세분화 |

```math
R_c^s=\min(D_c^s,\kappa_cq_c),\quad
O_c^s=(\kappa_cq_c-D_c^s)_+,\quad U_c^s=(D_c^s-\kappa_cq_c)_+.
```

공통 결정은 이진 진입과 정수 차량입니다. 초기 문서는 운영 가능성, 도시 수 한도, 진입 시 최소 차량도 논의하지만 현재 기본 모형에 모두 포함되지는 않습니다. 공헌이익과 부족 페널티에서 같은 손실을 중복 계산하지 않아야 합니다. 처리·유휴·부족은 수요·용량에서 계산되는 결과입니다. 이 폴더는 현재 실험 결과가 아닌 발전 과정입니다.
