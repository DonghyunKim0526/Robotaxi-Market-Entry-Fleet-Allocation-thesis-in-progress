# 참고자료·파라미터 근거: 한글

## 자료별 핵심

| 문서 | 핵심 내용 | 연구에서의 역할 |
|---|---|---|
| 비용항목 선정 근거 | 진입비·차량비·미충족 공헌이익 손실의 구조적 근거; 추가 유휴 페널티는 연구 가정 | 어떤 항을 목적함수에 넣는지 설명 |
| 파라미터 근거 | 관측 O / 발표 추정 E / 환산 D / 합성 가정 A 구분 | 수치의 출처와 실험값의 한계를 추적 |
| 모델 구조 가이드라인 | 기본 모형 → 경험적 잔차 기반 표본평균 근사(ER-SAA) → ER-DRO → 결정의존 확장 비교 | 도시 특성 정보, 강건성, 결정의존성을 구분 |
| 메모 | 종속변수 정의, 자료 부족, 변수 선택·잔차·외삽 검토 과제 | 확정 결론이 아닌 연구 검토 기록 |

## 수식으로 보는 차이

```math
\text{기본 모형: }\min_{y,q}\sum_c(F_cy_c+K_cq_c)+\frac1N\sum_s H(q,D^s)
```

```math
\text{맥락 기반 분포강건 모형: }\min_{y,q}\text{1단계 비용}
+\sup_{P\in\mathcal U(x)}\mathbb E_P[H(q,D(x,\varepsilon))].
```

맥락 기반 모형은 도시 특성 $x$에 따라 시나리오가 달라지는 것이며, 결정의존은 수요 자체가 $D(x,q,\varepsilon)$처럼 차량 배치 등에 반응하는 것입니다. 현재 ER-DRO 코드는 전자만 포함합니다. 개정 모형은 별도 $Kq$를 생략해 기본 모형과 비용 정의가 다릅니다.

파라미터 기준값은 $\kappa=8,760$, 기준 시장규모 $M=770,544,140$, $F=3.5$M, $K=7,972$, $c^+=0,c^-=10$입니다. 이는 서로 다른 출처의 규모 참고·환산·가정을 결합한 합성 설정입니다. 한글·영문 파라미터 PDF와 실제 연간 실험 코드의 $p$ 범위는 일치하지 않으므로 실행 결과는 코드의 실제 입력을 기준으로 읽으세요.
