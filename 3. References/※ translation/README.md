## A. 비용항목 선정 이유

A는 **목적함수 구조**의 근거이며 실제 금액 보정이 아닙니다. 문헌 구조 차용, 비용 분류 참고, 연구 추가 가정을 구분합니다.

| 비용항 | 주요 문헌·이유 | 모형의 의미 |
|---|---|---|
| 진입비 | Sun·Yu·Bayraksan의 EV 입지, Zhang 등의 차량·충전 계획 | 차량당 비용과 구분되는 고정 진입 부담 |
| 차량비 | EV 입지, Bösch의 자율주행 비용 분류, Fan의 SAV 계획, 차량·충전 계획 | 같은 기간의 차량 고정비와 통행당 변동비 구분 |
| 추가 유휴 페널티 | 직접 근거 문헌 미확정 | 별도 선호·손실 가정이며 차량비와 중복 금지 |
| 미충족 손실 | EV 부족비용 구조·SAV 서비스 계획·자율주행 비용 분류 | 총요금이 아닌 상실 공헌이익으로 해석 |

문헌이 비용 구조를 지지한다고 현재 금액을 제공한 것은 아닙니다. 유휴 페널티는 이미 청구한 보유비 외의 추가 근거가 필요합니다.

## B. 실험 파라미터 설정 과정

O는 특정 표본의 보고 관측, E는 발표 추정, D는 산술 환산, A는 합성 실험 가정입니다. 규모 참고가 있다고 범위 전체가 실증 검증되는 것은 아닙니다.

| 파라미터 | 기준값·산출 | 근거와 한계 |
|---|---|---|
| 생산성 | 24건/일×365=8,760 | 보고 통행·차량 규모의 환산 참고이며 실제 최대 용량 아님 |
| 시장규모 | 38,527,207건/0.05=770,544,140 | SFCTA·SFMTA의 기간·모집단·통행 단위 차이를 허용한 대리값 |
| 진입비 | (0.3M+2.5M)×1.25=3.5M 달러 | Austin 공사 추정+25% 준비비 가정, 실제 도시별 지출 아님 |
| 차량 연간비 | 7,972달러 | AAA 개인 신차 비용 구성의 대리값, 로봇택시 관측 운영비 아님 |
| 유휴 계수 | 기준 0, 양수는 민감도 | 추가 유휴 손실·선호 가정 |
| 부족 계수 | 미충족당 10달러 | 요금은 규모 참고; 유보요금 18−증분비 8은 예시 가정이지 연구의 추정 마진 아님 |
| 자원·선택확률 | 전체 1,000·도시 500, 시나리오 값은 사례별 지정 | 회사의 실제 최적 공급·보정 선택확률이 아닌 실험 가정 |

### 민감도 범위의 의미

생산성·시장규모·진입비·차량비의 ±25%와 다른 자원·페널티를 비교해 가정 변화에서도 작동 원리가 유지되는지 봅니다. 신뢰구간·실제 도시 운용 범위를 뜻하지 않습니다.

연간 실행 코드는 용량 근처의 선택확률 0.002·0.005·0.01·0.02를 쓰며 파라미터 PDF의 탐색값과 다릅니다. 한글·영문 PDF 간 확률 범위도 다릅니다. 실제 설정은 [영문 연간 실험 안내](../../1.%20model/B.%20baseline_model/2%29%20numerical_experiments/large_case/README.md)와 코드에서 확인합니다.

## A와 B를 함께 읽는 방법

**A는 무엇을 비용으로 넣는지**, **B는 실험값을 어떻게 얻었는지**를 설명합니다. 단위·기간·출처 범위·중복 비용·관측/환산/가정을 확인해야 합니다. 투명한 합성 검증의 근거이지 실도시 보정 완료를 뜻하지 않습니다.

[C. 모델 구조 가이드라인](C.%20Model%20Structure%20Guidelines.pdf)은 모형군의 차이, [논문 안내](../%E2%80%BB%20papers/README.md)는 방법론 근거를 설명합니다. 개정 ER-DRO는 기본 모형과 비용 정의가 달라 목적값을 그대로 옮겨 비교하지 않습니다.
