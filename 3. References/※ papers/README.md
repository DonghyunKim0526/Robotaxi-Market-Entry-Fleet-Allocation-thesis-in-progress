# Supporting papers

Papers organized by their role in the research, rather than by publication date.

## Folders

- [A. multi_sourced_data](A.%20multi_sourced_data/README.md) — Research on optimization with multiple information sources and uncertain source reliability.
- [B. distributionally_robust_optimization](B.%20distributionally_robust_optimization/README.md) — Foundations of ambiguity sets, optimal transport, and heterogeneous data sources.
- [C. contextual_stochastic_optimization](C.%20contextual_stochastic_optimization/README.md) — Tutorials, surveys, and residual-based optimization with covariates.
- [D. other_related_papers](D.%20other_related_papers/README.md) — Spaceport location and resource-distribution applications for structural comparison.
