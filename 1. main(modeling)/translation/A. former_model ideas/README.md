# 초기 모형 검토

## 초기 모형에서 비교하는 것

| 모형 | 목적함수의 핵심 | 해석 |
|---|---|---|
| 기본 newsvendor | 기대 유휴 용량 + 가중 미충족 수요 | 금전 자료가 부족할 때 배치의 기준선 |
| 비용형 | 진입비 + 차량비 + 유휴·부족 비용 | 추가 도시 진입의 고정비 반영 |
| 이익형 | 처리 통행의 공헌이익 − 진입·차량 비용 | 처리량과 수익의 연결 |
| 복수 페널티 | 유휴와 여러 미충족 결과를 구분 | 인간택시 전환 등 부족 후 결과를 명시 |

```math
R_c^s=\min(D_c^s,\kappa_cq_c),\quad
O_c^s=(\kappa_cq_c-D_c^s)_+,\quad U_c^s=(D_c^s-\kappa_cq_c)_+.
```

진입 $y$와 정수 차량 수 $q$를 함께 결정하며 도시별·전체 차량 상한을 둡니다. 이 초기 문서는 진입 시 최소 1대, 운영 가능성 $y_c\le a_c$, 진입 도시 수 상한도 논의합니다. 이들이 현재 baseline에 모두 들어가는 것은 아닙니다.

**핵심 주의점:** 공헌이익에서 이미 반영한 미처리 손실을 별도 부족 페널티로 다시 더하면 중복 계산이 됩니다. $R,O,U$는 수요·용량으로 계산되는 결과이지 별도 조사할 입력이 아닙니다. 수치실험 결과보다 모형 발전 과정과 정의를 이해하는 자료입니다.
