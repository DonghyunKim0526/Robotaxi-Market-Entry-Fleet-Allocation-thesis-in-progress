# ER-DRO model and experiments

Residual-based demand scenarios and a CVaR-type distributionally robust city-entry model.

- Read ER-DRO(revised).pdf first. The notebook compares contextual ER-SAA, contextual ER-DRO, and a no-context benchmark on a toy instance.
- The draft is retained for model development history.
