# Baseline model

Stochastic city-entry and integer fleet-allocation model with fixed market size and scenario-based robotaxi choice demand.

## Folders

- [1) baseline](1%29%20baseline/README.md) — Entry and vehicle costs plus expected unused-capacity penalties and unmet-demand losses.
- [2) numerical_experiments](2%29%20numerical_experiments/README.md) — Two synthetic instances test implementation correctness and parameter sensitivity.
- [3) revision_history](3%29%20revision_history/README.md) — Dated snapshots of earlier baseline formulations.
