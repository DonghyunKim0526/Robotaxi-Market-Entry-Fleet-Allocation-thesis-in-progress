# Distributionally Robust Resource Allocation with Trust-Aided Parametric Information Fusion

## One-Sentence Summary

This paper applies multi-reference DRO to a resource allocation problem by combining multiple predicted distributions through trust weights, constructing a Wasserstein ambiguity set around the fused distribution, and updating trust based on realized performance.

## 1. Big Picture

The paper studies resource allocation under uncertain demand.

The motivating application is wildfire suppression resource allocation. A planner needs to allocate limited resources across regions before the true demand is known.

Demand information may come from multiple sources, such as:

- drone data;
- satellite data;
- remote sensing;
- forecasting models.

Each source may provide useful but imperfect information. The question is how to combine these sources and make a robust allocation decision.

## 2. SP, DRO, and MR-DRO

### 2.1 Stochastic Programming

Stochastic programming assumes that the true demand distribution is known.

    minimize_x E_P[loss(x, ξ)]

If the distribution is correct, this can work well. But if the assumed distribution is wrong, the decision can be fragile.

### 2.2 Distributionally Robust Optimization

DRO does not fully trust one distribution.

    minimize_x sup_{Q in Pset} E_Q[loss(x, ξ)]

The ambiguity set contains plausible distributions near a reference distribution. DRO protects against distributional misspecification.

### 2.3 MR-DRO in This Paper

This paper uses multiple predicted distributions. Each source provides parametric distributional information, such as mean and variance.

For example, with drone and satellite sources, the fused mean for region `k` can be understood as:

    fused mean = trust × drone mean + (1 - trust) × satellite mean

The fused distribution is then used as the center of a Wasserstein ambiguity set.

## 3. Resource Allocation Structure

The decision is how much resource to allocate to each region.

If too little is allocated, there is unmet demand penalty.

If too much is allocated, there is over-served penalty.

The loss has a piecewise linear form:

    loss = unmet demand penalty + over-served penalty

This structure is important because it helps make the DRO model tractable.

## 4. Why Linear Programming?

The DRO model can be reformulated as a linear program because of the specific structure:

- the loss function is piecewise linear;
- resource constraints are linear;
- the uncertainty support is described by linear constraints;
- the Wasserstein distance uses an L1-type metric;
- duality converts the worst-case distribution problem into finite-dimensional constraints.

The original DRO problem looks infinite-dimensional because it optimizes over probability distributions.

The reformulation changes it into a finite-dimensional optimization problem with auxiliary variables and linear constraints.

The key intuition is:

> Instead of searching over all possible distributions directly, the reformulated model bounds the worst-case loss caused by perturbing empirical samples within the Wasserstein ambiguity set.

## 5. Reformulation Intuition

The reformulation can be understood in steps:

1. Start with a Wasserstein ambiguity set around the fused empirical distribution.
2. Consider the worst-case expected loss within that ambiguity set.
3. Use duality to replace the worst-case distribution problem with a finite optimization problem.
4. Because the loss and support structure are linear or piecewise linear, the final formulation becomes an LP.

The worst-case distribution can be understood as moving empirical scenarios in harmful directions, while the Wasserstein radius controls how far they can move.

This is why the paper is computationally practical despite starting from a distributionally robust problem.

## 6. Computational Results

The paper compares MR-DRO with single-source DRO and stochastic programming.

In the baseline resource allocation setting, MR-DRO has lower average loss than drone-only or satellite-only approaches.

One reported result is:

- MR-DRO average loss: 155.79;
- drone-only DRO average loss: 325.11;
- satellite-only DRO average loss: 775.03.

This supports the idea that trust-based fusion can reduce the weakness of relying on one source.

When the budget is tighter, MR-DRO still performs better than single-source alternatives.

The practical interpretation is that fusing sources based on trust can reduce both under-allocation and over-allocation when individual sources are imperfect.

## 7. Difference from the Unknown-Trust MR-DRO Paper

This paper and the unknown-trust MR-DRO paper are closely related, but their emphasis is different.

The unknown-trust MR-DRO paper provides a broader framework for multiple sources with dynamically updated trust.

This paper focuses on a specific resource allocation problem and uses parametric information fusion.

Important differences:

- this paper assumes sources provide predicted distributions;
- it combines parametric distribution information such as mean and variance;
- it applies the method to wildfire-style resource allocation;
- trust is updated based on realized loss or prediction performance;
- the final model is reformulated into a tractable LP.

## 8. Limitations

Several assumptions are important from a statistics perspective.

### 8.1 Normal Distribution Assumption

The paper assumes parametric distributions, often normal.

Real demand can be:

- skewed;
- heavy-tailed;
- multimodal;
- spatially correlated;
- affected by extreme events.

This creates a natural statistical extension: test what happens when the normal assumption is violated.

### 8.2 Fixed Reliability Structure

Source reliability may not be constant across all events.

For example, drone data may be more reliable in clear weather but less reliable in smoke. Satellite data may be more reliable at broad spatial scales but less useful for local details.

This suggests context-dependent trust.

### 8.3 Static One-Stage Decision

The wildfire resource allocation example is modeled as a one-stage allocation problem.

Real wildfire response is dynamic. New information arrives over time, and resources can be reallocated.

This suggests possible extensions to dynamic or multi-stage resource allocation.

### 8.4 Synthetic Data

The numerical study is closer to synthetic simulation than a fully real-data empirical study.

This matters because actual trust estimation requires historical multi-source prediction data and realized outcomes.
