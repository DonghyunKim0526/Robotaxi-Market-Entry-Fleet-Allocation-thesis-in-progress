# Unifying Distributionally Robust Optimization via Optimal Transport Theory

## One-Sentence Summary

This paper provides a theoretical framework that unifies different forms of distributionally robust optimization, especially Wasserstein DRO and phi-divergence DRO, using optimal transport theory.

## 1. Big Picture

The paper is more theoretical than the applied MR-DRO and charging station papers.

Its purpose is to explain how different DRO models can be viewed under a common framework.

In DRO, there are several ways to define the ambiguity set. Two important families are:

- phi-divergence DRO;
- Wasserstein DRO.

These approaches may look different, but this paper shows that they can be connected through optimal transport.

## 2. Why This Paper Matters

When reading DRO papers, one confusing point is that different papers use different ambiguity sets.

For example:

- some use KL divergence;
- some use chi-square divergence;
- some use Wasserstein distance;
- some use moment constraints;
- some combine different types of uncertainty.

This raises practical questions:

> Are these DRO models fundamentally different, or are they variations of a broader idea?

This paper helps answer that question by showing a unifying perspective.

## 3. Phi-Divergence DRO

Phi-divergence DRO controls how much the probability weights can change relative to a nominal distribution.

The support points usually stay fixed, but their probabilities can be reweighted.

Intuitively:

> The same observed scenarios remain, but the worst-case distribution can put more probability mass on harmful scenarios.

This type of DRO is useful when we trust the observed sample values but are uncertain about their probabilities.

## 4. Wasserstein DRO

Wasserstein DRO allows probability mass to move in the uncertainty space.

Intuitively:

> The observed scenarios themselves can move to nearby values, and the model protects against harmful perturbations.

This is useful when the empirical sample values may not exactly represent future realizations.

For example, demand values, travel times, or returns may shift away from historical observations.

## 5. Key Difference Between Phi-Divergence and Wasserstein DRO

The main difference can be understood like this:

```text
Phi-divergence DRO:
Change the probability weights on existing scenarios.

Wasserstein DRO:
Move the scenarios themselves in the uncertainty space.
