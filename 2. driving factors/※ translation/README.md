## 수요는 시장규모×선택확률

```math
D_c=M_cp_c,\qquad M_c=\sum_gN_{c,g}r_g.
```

M은 잠재 이동 기회, p는 차량 부족 전 로봇택시 선택비율입니다. 관측 통행과 연관된 요인이 두 성분 중 어느 쪽을 바꾸는지는 별도 구분이 필요합니다.

| 연구 단계 | 핵심 결론 | 모형에 대한 의미 |
|---|---|---|
| 배경 근거 | 실제 로봇택시·일반 호출·선택실험은 다른 대상을 측정 | 근거 범위와 단위 구분 |
| 후보 선별 | 인구·활동은 규모, 요금·대기·차량 접근·태도는 선택 후보 | 모든 후보 도시의 공통 측정 가능성 확인 |
| 입력 설계 | M은 인구 구성×통행률, p는 외생 특성으로 추정 | 분리되지 않은 같은 통행 총량에서 둘을 각각 추정하지 않음 |

## 현재 선정 방향

- **M:** NHTS 집단 통행률×ACS 집단 인구로 고정 시장규모 구성. 지역·연도·통행 포함범위·가구/개인 단위를 맞춥니다.
- **p의 초기 외생 변수:** 무차량 가구 비율·연령 구조. 현재 합성 ER-DRO는 무차량 비율만 사용합니다.
- **결정의존 확장:** 자사 요금·대기시간·지원기능은 서비스/선택 대응 자료가 필요합니다.
- **별도 운영 조건:** 허가·ODD는 선택확률과 구분합니다.

완료 통행/M은 공급 부족이 반영된 이용비율일 수 있습니다. 요청·거절 자료로 조정하거나 왜곡이 작다는 가정이 필요합니다. 현재는 정의·선정 방향이며 실제자료 적합 모형이 아닙니다.
