# 수요 변수 선정: 한글 자료

## M: 도시별 잠재 시장을 고정 입력으로 구성

```math
M_c=\sum_gN_{c,g}r_g=\mathrm{인구}_c\sum_g\pi_{c,g}r_g.
```

NHTS에서 차량 보유·소득 등 집단별 연간 1인당 통행률 $r_g$를 구하고, ACS의 도시별 집단 인구 $N_{c,g}$와 곱합니다. 도시 차이는 인구 규모·구성에서 발생합니다. 자료 확인 전의 방법 가이드이므로 실제 도시별 산출이 완료된 것은 아닙니다.

집단별 표본 수, 가구·개인 단위, PUMA→도시 집계, 조사연도·경계·통행 포함범위를 맞춰야 합니다. 국가 평균 통행률을 각 도시로 옮기는 가정은 지역 MPO 조사 총량과 비교해 검증합니다.

## p: 선택확률의 변수 선별

| 역할 | 우선 변수 | 적용 조건 |
|---|---|---|
| 외생 도시 특성 | 무차량 가구 비율, 연령 구조 | 모든 후보 도시에서 동일 정의로 측정; 현재 합성 실험 코드는 무차량 비율만 사용 |
| 결정의존 확장 | 상대 요금, 대기시간, 차내 지원기능 | 서비스 변경과 선택 결과의 대응 자료 필요 |
| 별도 운영 조건 | 규제·허가, 기후/ODD | 선택확률의 회귀변수와 운영 가능성을 구분 |

```math
p_c^{\mathrm{obs}}=\frac{\text{도시 }c\text{의 로봇택시 통행}}{M_c}.
```

분자·분모의 기간·지역·통행 단위가 같아야 합니다. 완료 통행만 쓰면 공급 부족이 반영되므로 미실현 선택수요를 과소평가할 수 있습니다. 요청·거절 자료로 보정하거나 공급 제약이 작다는 가정이 필요합니다.

후보 문서는 폭넓은 선별 목록, M·p 문서는 최종 역할과 기준을 정리합니다. 실제 수요·일반 차량 호출 서비스·선택실험 근거를 구분하고, 추정 후 잔차·외삽·변수 중복을 검사해야 합니다.
